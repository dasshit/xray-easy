## Критерии достижения 100%

- Coverage остаётся 100% по statements, branches, functions и lines как
  глобально, так и для каждого включённого production-файла. Не исключать
  исполняемый код и не ослаблять пороги.
- В том же ручном аудите все пять категорий имеют 4/4, без подтверждённых
  незакрытых P1/P2 замечаний. Полный счёт — 20/20.
- Текст обычного размера имеет контраст не ниже 4,5:1, крупный текст — 3:1,
  а необходимые графические состояния и границы фокуса — не ниже 3:1.
- Все модальные окна удерживают клавиатурный фокус, закрываются штатной
  клавишей Escape там, где это предусмотрено, и возвращают фокус инициатору.
  Вкладки поддерживают стрелки, Home и End, имеют согласованные tab/panel
  связи и корректно работают при RTL.
- На ширинах 320, 360, 390, 768, 1024 и 1280 CSS px нет горизонтального
  переполнения страницы, наложения элементов и недоступных основных действий;
  каждую вкладку можно обнаружить и выбрать.
- Переключатель темы видим и имеет цель не меньше 44×44 CSS px; обе темы
  проходят проверку контрастности и фокуса.
- Ошибки API в пользовательском интерфейсе показываются на выбранном языке.
  Impeccable detector не оставляет подтверждённых необработанных находок;
  ложные срабатывания сверяются с `DESIGN.md` и документируются.
- Сборка сохраняет бюджет не более 110 KiB JS gzip и 5,5 KiB CSS gzip;
  `lint`, `typecheck`, unit-покрытие и production build проходят.
